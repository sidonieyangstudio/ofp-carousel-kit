# OFP 套版工具（歐的樂星球 Carousel Kit）

歐的樂星球使用的 IG 輪播圖 / FB 配圖快速套版工具。單一 HTML 檔，
在瀏覽器中運作，不需要後端服務，也不會加入追蹤碼。

## 線上使用

部署到靜態網頁服務後，可直接在手機或桌機瀏覽器使用。

## 本機啟動

直接打開 `index.html` 即可；若瀏覽器限制字型載入，可用下列方式開啟：

```bash
cd ofp-carousel-kit
python3 -m http.server 8765
```

## 字型

- **粉圓（jf-openhuninn-1.1）** — 開源字型，已內嵌 + CDN fallback
- **Google Fonts** — Chiron GoRound TC / Nunito / Jost（CDN 載入）
